## 💬 Sobre mim

Sou estudante de Sistemas de Informação e atuo como estagiária de desenvolvimento backend na CERMOB Tecnologia, onde construo e evoluo uma API REST em Python com FastAPI desde o zero — com autenticação JWT, controle de acesso baseado em papéis (RBAC), criptografia de dados sensíveis e tratamento adequado de erros HTTP.

Também tenho base sólida em front-end e mobile (JavaScript, React, Kotlin, Swift, Flutter), o que me ajuda a enxergar o produto como um todo. Venho me aprofundando em bancos de dados e cibersegurança, e trato aprendizado contínuo como parte do trabalho, não só uma etapa antes dele.

Fora do código: música, carros, livros, moda e maquiagem — minha [página pessoal](https://luizasouza.eti.br) tem mais sobre meus projetos.
